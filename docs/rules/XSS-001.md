# XSS-001: Unescaped output in Blade

**Severity:** High, Medium or Low, depending on the source · **CWE-79**

## What it finds
`{!! ... !!}` echoes, graded by where the value comes from:

| Severity | When |
|---|---|
| High | The expression reads the request directly: `request()`, `old()`, `Request::`, `$_GET` |
| Medium | Markdown rendering (`Str::markdown`, `->markdown()`) without `'html_input' => 'strip'`. CommonMark passes raw HTML through by default. |
| Low | Any other dynamic value. It's unescaped, so check that it's sanitised. |

## How to fix
Use `{{ }}`. For rich text, sanitise it on input or output with an HTML purifier. Render Markdown with
`Str::markdown($text, ['html_input' => 'strip', 'allow_unsafe_links' => false])`.

## Not reported
- Literal strings.
- `csrf_field()`, `method_field()` and paginator `->links()`.
- Component `$slot` and `$attributes`.
- Literal translation keys without replacements.
- `nl2br(e(...))`, and `Vite::`/`Js::` helpers.
- Anything inside `{{-- --}}` or `@verbatim`.
