# CFG-001: Debug mode enabled for production

**Severity:** High (Medium for staging, or for a `true` fallback in config) · **CWE-489**

## What it finds
- `APP_DEBUG=true` in `.env.production*`, or in any root `.env*` file that sets `APP_ENV=production`.
- `APP_DEBUG=true` in `.env.staging*`.
- `config/app.php` hard-coding `'debug' => true`, or falling back to `true` when `APP_DEBUG` is missing.

Debug pages expose stack traces, environment variables and secrets.

## Not reported
`.env.example`, `.env.testing`, `.env.local`, and local development `.env` files.
