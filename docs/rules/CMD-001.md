# CMD-001: User input reaches a shell command

**Severity:** Critical · **CWE-78**

## What it finds
Request data in a command string that runs through a shell. Covered calls:
- `exec`, `shell_exec`, `system`, `passthru`, `proc_open`, `popen` and backticks
- `Process::run('...')` and `Process::fromShellCommandline()`

```php
exec("convert {$request->input('file')} out.pdf");   // reported
```

## How to fix
Pass an argument array so no shell is involved:

```php
Process::run(['convert', $path, 'out.pdf']);
```

If you must build a string, escape each argument with `escapeshellarg()`.

## Not reported
- Array-form commands (`Process::run([...])`, `proc_open([...])`).
- Arguments wrapped in `escapeshellarg()` or `escapeshellcmd()`.
- Values that are typed `int` or cast to a number.
